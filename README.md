# Kedi Mama Kabı Anayasa Mahkemesi

> Resmi slogan: Kase boşsa devlet de boştur. Doldurun, sonra konuşuruz.

Bu depo, evcil kedinin mama kabındaki gramaj düştüğü anda kendiliğinden toplanan, kararları bağlayıcı, gerekçeleri şiirsel, infazı ise “bir poşet aç” olan yüce bir yargı organıdır. Yargıtay değiliz. Danıştay değiliz. Biz **Mamaştay**ız.

Patates bu mahkemede delil değil, tanık değil, yem değildir. Kapıdan çevrilir.

## Neden var?

Çünkü bir kedi, kabına bakıp sana baktığı anda ülkenin anayasal düzeni fiilen askıya alınmış sayılır. Bilim bunu henüz kabul etmedi. Biz kabul ettik. Kabul tutanağı bu README’dir.

## Kurulum

```bash
git clone https://github.com/Tentivory/kedi-mama-kabi-anayasa-mahkemesi.git
cd kedi-mama-kabi-anayasa-mahkemesi
python3 mahkeme.py --kedi "Pamuk" --gram 12 --kapasite 80
```

Bağımlılık yok. Sadece Python 3 ve bir miktar vicdan. Vicdan opsiyoneldir, kedi değildir.

## Kullanım

```bash
python3 mahkeme.py --kedi "Lokum" --gram 0 --kapasite 90 --aciliyet gece
python3 mahkeme.py --kedi "Tarçın" --gram 70 --kapasite 80 --itiraz "daha yeni koydum"
```

Çıktı bir karardır. Karar kesinleşir. Temyiz yolu: kabı doldurup programı tekrar çalıştırmak.

## İçtihat

| Kase doluluk | Hüküm |
| --- | --- |
| %0 | Derhal infaz. Poşet açılır. Gerekirse ikinci poşet de açılır. |
| %1–25 | İhlal vardır. Kedi haklıdır. Sen değilsin. |
| %26–60 | İhtiyati tedbir: bir avuç daha. |
| %61–89 | Dava reddedilir, kedi yine de küsme hakkını saklı tutar. |
| %90+ | Anayasa ihlali yok. Kedi yine de drama yapabilir; bu serbesttir. |
